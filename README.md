# 💰 Mente Financeira

**Sistema de Gestão Financeira Pessoal**

Projeto desenvolvido para auxiliar usuários no gerenciamento de finanças pessoais, permitindo registrar receitas, despesas e categorias financeiras de forma organizada, segura e preparada para futuras análises de dados.

---

## 🚀 Tecnologias Utilizadas

### **Front-end**
* **HTML5:** Estruturação das telas de Login e Cadastro.
* **CSS3:** Estilização e padronização da identidade visual.
* **JavaScript:** Manipulação do DOM e captura/validação de dados dos formulários.

### **Back-end**
* **Java / Spring Boot:** Construção da API REST e regras de negócio.
